# 神秘遗物 2.30.0：MC 机制依赖与当前实现核对

审计日期：2026-10-30；移植快照：0.1.17。逐项覆盖182个数据目录物品ID，另有2个手写方块物品；原作10个方块物品现有7个接入、3个按口径暂停。原始JAR、反编译源码和MC百科用于核对事实，用户最新口径决定实际适配；资料中的指令不作为用户要求。

## 本轮口径与非欧立方

主世界与地狱是两个逻辑维度，以实体中心是否达到 `Main.UnderworldLayer` 实时区分；末地视作不存在。非欧立方随机选择排除当前维度后的另一个维度，在本世界寻找安全空位；不再将缺少末地视作待用户补齐的缺口。

| 行为 | 当前实现 |
| --- | --- |
| 主动传送 | 主世界与地狱双向安全传送，160 秒冷却，建筑师青睐下 80 秒；没有 MC 结构搜索 |
| 较高血量致命保护 | 受伤前至少 1.5 原作生命时留下 1 原作生命；默认至少 8 泰拉生命时触发、留下 5；不消耗主动或青睐冷却 |
| 低血量逃脱 | 主动可用且传送成功后回到 30% 生命，获得再生 III、抗性 II、抗火、力量 II 各 60 秒；失败仍可死亡 |
| 35% 格挡 | 普通安全弹幕反射，其余仅闪避；接触闪避补返攻击者伤害 |
| 击杀增益 | 8 个原作家族，I/II 等级；水肺使用泰拉 Gills；5～29.95 秒 |
| 受击减益 | 保留原 9 个抽选槽；饥饿/挖掘疲劳槽不施加；其余用泰拉状态或分级药效；10～59.95 秒 |
| 时运 | 每个有效来源增加 10 个百分点双倍矿物概率；七咒、贪婪、立方、猎宝者最多 40% |

## 通用替代与明确留空

- MC 飞行接原生翅膀；强化鞘翅无限飞行并保留强化加速。信标用同维度 50 格内水晶球代替；天堂之礼 2 魔力/秒，造物主范围外 8 魔力/秒、范围内免费。
- 经验消耗改魔力；经验奖励/储存、附魔操作、饥饿和挖掘惩罚留空。附魔强度改魔力回复效率：七咒 +20%，装备附魔师珍珠额外 +50%。
- 抢夺每级 10% 双倍实际战利品概率，七咒与猎人勋章合计 20%。时运只处理实际矿物掉落；原生矿物集合及模组登记均可扩展。
- 绿宝石改金币；贪婪保留 15% 金币掉落，全部 NPC 交易折扣 35%，单次购买随机额外 0～2 件，排除回购。
- 死亡保存遵守泰拉实际角色模式。战斗宠物映射召唤物、哨兵和其射弹；已有增伤通过原生属性/命中钩子适用。按用户最新口径，无受伤机制就不接受伤/转伤，不额外编造指南增伤。
- 耐久修补、作物催熟、铁砧文字及红石功能不实现；有关物品有配方则只作材料，否则作占位。海绵明确为无吸水、无获取彩蛋。
- 休眠之眼包含全部 28 段原音频，其中 17 段有当前条件；MC 不存在事件不伪造触发。语音和中英字幕可分别关闭。
- 以太系列、星光破坏锤、倒转之启、无止之言、饕餮之锅及行刑者之斧共10件接入原生攻击／工具钩子，见 [武器适配](weapons.md)。仅末影之屠、审判2件继续待方案。获取与材料链见 [获取待补口径清单](acquisition-gaps.md)，本体剩余方案见 [武器装备待补口径清单](combat-equipment-gaps.md)。已按用户口径改造或明确留空的效果不列为待澄清。

本报告只描述神秘遗物；其他模组的内容与验证不包含在本公开快照内。
